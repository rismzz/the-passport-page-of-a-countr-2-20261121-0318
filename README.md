An invented passport spread for the Republic of Zalvara — a country that does not exist. A pure-Python (PIL) program renders one open-passport spread as a 1024×1024 PNG: a data page with a drawn portrait, machine-readable strip and issue details, and a visas page with four arrival/departure stamps from neighbouring invented countries, a visa-condition box for the Northern Isles, and a fee stamp. Every stamp is dated after the passport's issue (14 MAR 2024) and the stamps run in chronological order; no real country, place, or person appears anywhere.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, under 1 MiB).
